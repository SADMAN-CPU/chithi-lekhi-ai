# 🌸 About The Project

**Chithi Lekhi AI** brings back the emotional beauty of handwritten letters in the modern digital era.

In today's world of instant messaging, emotions are often expressed quickly but rarely preserved deeply.

Chithi Lekhi AI combines:

- Artificial Intelligence
- Emotional understanding
- Bengali cultural storytelling
- Vintage letter design
- Modern sharing technology

to create meaningful digital memories.

> "Every feeling deserves a letter."

# ⚙️ Installation


## Prerequisites


Make sure you have:


- Node.js 20+
- npm
- Supabase account
- Gemini API Key



---

## Clone Repository


```bash
git clone https://github.com/yourusername/chithi-lekhi-ai.git

cd chithi-lekhi-ai
```


---

## Install Dependencies


```bash
npm install
```


---

## Environment Setup


Create:


```
.env.local
```


Add:


```env
NEXT_PUBLIC_SUPABASE_URL=

NEXT_PUBLIC_SUPABASE_ANON_KEY=

SUPABASE_SERVICE_ROLE_KEY=

GEMINI_API_KEY=

OPENAI_API_KEY=
```



---

# 🚀 Run Development Server


```bash
npm run dev
```


Open:


```
http://localhost:3000
```
